# Apex v1.7

Simple benchmark module.

## What's new

- **Benchmark** — New `Modules/Benchmark.ps1`. Press `b` for a quick in-session sample (responsiveness, optional Notepad launch timing, current uptime).
- Before/after comparison, hardware warnings, profiles, Expert mode, adaptive tweaks, and modular structure remain.
- Safe / Advanced / Extreme presets, restore points, dry-run, and selective revert unchanged.

## Download

- Download `Apex.bat`, `Apex.ps1`, and the `Modules` folder.
- Right-click `Apex.bat` → Run as administrator.
- `s` Safe, `ad` Advanced, `e` Extreme, `x` Expert, `p` Profile, `m` Metrics, `w` Warnings, `b` Benchmark, then `a` to apply.

## Safety

Nothing changes until you apply. Restore point is attempted. High-risk items always ask for confirmation. Hardware warnings can add an extra check.
