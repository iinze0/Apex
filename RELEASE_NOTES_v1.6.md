# Apex v1.6

Before/after comparison, hardware warnings, and further modularization.

## What's new

- **Before/after comparison** — Press `m` to see the latest before and after metrics with simple deltas (free RAM, processes, responsiveness).
- **Hardware warnings** — New `Modules/Warnings.ps1`. Press `w` to view warnings. High-risk options now prompt an extra confirmation when hardware warnings are present.
- Modular structure continues. Profiles, Expert mode, adaptive tweaks, and metrics remain.
- Safe / Advanced / Extreme presets, restore points, dry-run, and selective revert unchanged.

## Download

- Download `Apex.bat`, `Apex.ps1`, and the `Modules` folder.
- Right-click `Apex.bat` → Run as administrator.
- `s` Safe, `ad` Advanced, `e` Extreme, `x` Expert, `p` Profile, `m` Metrics, `w` Warnings, then `a` to apply.

## Safety

Nothing changes until you apply. Restore point is attempted. High-risk items always ask for confirmation. Hardware warnings can add an extra check.
